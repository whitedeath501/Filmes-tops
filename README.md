Explicação das funções:

Funções do JavaScript
favoritar(botao)

Essa função é usada quando a pessoa clica no botão de favoritar. Ela muda o botão de "Favoritar" para "Favoritado" e deixa ele verde. Se clicar de novo, desfaz e volta ao normal.

pesquisar()

Essa função serve para pesquisar os filmes. Ela pega o que a pessoa digitou na barra de pesquisa e procura esse texto nos nomes dos filmes. Os filmes que combinarem continuam aparecendo e os que não combinarem desaparecem.

mostrarTodos()

Essa função faz todos os filmes aparecerem novamente. Ela também apaga o que estiver escrito na barra de pesquisa.

filtrarFavoritos()

Essa função serve para mostrar só os filmes que foram favoritados. Ela olha cada filme e verifica se ele está marcado como favorito. Se estiver, ele aparece na tela; se não estiver, fica escondido.

verDescricao(filme)

Essa função mostra uma informação sobre o filme quando a pessoa clica no botão Info. Ela recebe o nome do filme e verifica qual é para mostrar a descrição correta em uma caixinha de aviso.

voltarInicio()

Essa função faz a página voltar para o início quando o botão Início é clicado. Além de voltar para o topo, ela também mostra todos os filmes novamente.
